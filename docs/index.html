How Canopy works

A plant is a graph of nodes. A Spline node is one part of the plant: a line (its length and steps, bent by modifiers), where those lines start (Placement), what wraps them (a tube, leaf blades or cutout leaves), how they look (a material) and how they move (wind). A Mesh node is a solid shape placed as copies, which other parts can also grow on.

Connect a node's Children output to another node's Parent input to grow the second from the first: branches from a trunk, twigs from branches, leaves from twigs. Each setting can vary from copy to copy (±) and follow a curve along its line or up the chain (the curve icon). Right-click a value to expose it as sockets, copy, paste or reset it.

Materials are shared: change one and every node using it changes. A material's leaf picture is cut into cutouts in the cutout editor, and each node can use some or all of them.
